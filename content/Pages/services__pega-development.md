## PEGA Tools & Technologies We Use

#### App Studio

Low-code interface used to rapidly design and configure applications, case types, data models and user interfaces.

#### Dev Studio

Advanced development environment for creating complex rules, integrations, and backend logic within PEGA.

#### PEGA Deployment Manager

Automates CI/CD pipelines and promotes application packages across development, staging and production environments.

#### PegaUnit

Built-in framework used for unit testing individual rules and validating application logic during development.

#### Pega API Explorer

Tool for exploring and testing REST and SOAP services exposed by PEGA applications for third-party integrations.

#### Pega Mobile Builder

Used to generate and manage mobile-ready PEGA applications with native functionality and offline capabilities.

#### Pega Predictive Diagnostic Cloud (PDC)

Real-time monitoring and diagnostics platform used for health checks and performance optimisation of live PEGA applications.

#### Pega App Factory

Centralised platform for governing, managing and scaling PEGA applications across the enterprise.
