## POS Testing Tools & Technologies We Use

#### Selenium

Automated browser-based testing to ensure consistent UI behaviour across different web browsers and screen resolutions.

#### JUnit

Verifies backend service compatibility with different Java versions and server configurations.

#### LoadView

Tests cloud-hosted POS under varied load scenarios to validate stability across server setups and geographical regions.

#### JMeter

Validates consistent performance under concurrent users across environments (OS, network types).

#### Postman

Ensures API response consistency across environments and validates integration compatibility with payment/inventory services.

#### BrowserStack

Performs cross-browser and cross-device testing to ensure compatibility across Android, iOS, Windows, macOS.

#### Fiddler

Monitors network traffic to validate consistent communication between POS and backend systems under varied proxy/firewall setups.

#### VirtualBox

Simulates different OS environments (Windows/Linux/macOS) to test installation and execution compatibility of POS software.
